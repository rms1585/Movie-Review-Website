  1. Its own page, with a centred column about 680px wide on desktop, because writing needs focus. Mobile goes full width (Spec §7.5).
  2. Score saves the moment it's clicked. A rating alone counts. Click a number to see "Saved ✓". Desktop shows 1–10 in one row; mobile uses two rows of five.

  1. Desktop: a centred dialog. Mobile: a bottom sheet. Either way the film stays visible behind it, so the user keeps their context (Flow 4).
  2. The copy names the action ("to rate this film", "to save to watchlist"), so the reason is clear.
